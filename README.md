# House of Horani — site

Static responsive build (desktop 1440 / mobile 375, breakpoint 760 px), synced with the Figma file.

## Pages
- `index.html` — home
- `bois-mira.html`, `fleur-zubyan.html`, `baryshnikova.html`, `ambre-rouge.html`, `oud-ethalon.html` — fragrances
- `discovery-set.html`, `concept.html`, `dejeuner.html`, `about.html`
- `shipping-returns.html`, `faq.html` (with "Ask a question" popup), `contact.html`
- `privacy-policy.html`, `cookie-policy.html`, `terms-of-service.html`, `refund-policy.html`
- `sign-in.html`, `account.html`, `checkout.html`, `thank-you.html`
- `404.html`, `502.html`

## Shared
- `css/site.css`, `js/site.js` — bag / wishlist drawer with tabs (right panel on desktop, full width under the header on mobile), mobile menu, popups
- `css/pages.css`, `js/page.js` — content and service pages
